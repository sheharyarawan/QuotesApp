# Quotes App

A simple Quotes App built using Jetpack Compose as part of my transition from XML-based Android UI development to modern Android development with Compose.

## Features

* Display a list of inspirational quotes
* View quote details on a separate screen
* Clean and modern UI with Material 3
* Built entirely with Jetpack Compose
* State-based screen navigation

## Tech Stack

* Kotlin
* Jetpack Compose
* Material 3
* Android Studio

## What I Learned

* Creating reusable composables
* Working with LazyColumn
* State management using `remember` and `mutableStateOf`
* Managing UI state for screen navigation
* Organizing projects using model, data, screens, and components packages


## Getting Started

1. Clone the repository
2. Open the project in Android Studio
3. Build and run the app
